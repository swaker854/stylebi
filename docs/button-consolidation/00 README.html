Watch-outs — easy to miss

Four things that aren't mechanical

  • Lint must honour *ngIf. The 2+-primaries check over-counts mutually-exclusive buttons — expert-named-group is a false positive (only one branch renders). Count only buttons that can render simultaneously.
  • Never auto-apply .is-danger from a label. 30 of the 59 destructive labels are reversible resets (Clear/Reset) — flag candidates for review, don't blanket-replace, or harmless buttons turn red.
  • One manual class change: analyze-mv-dialog:54 "Delete" goes btn-primary → btn-ghost.is-danger. The other 28 danger sites become ghost via the default/light codemod and just gain .is-danger.
  • Label copy is deferred, not done. Switching generic "OK" to action verbs ("Abandon", "Discard") is a separate, i18n-touching initiative — out of scope for this PR. Don't fold it in.
